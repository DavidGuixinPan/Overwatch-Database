# Overwatch-Database

A user will be able to search up an Overwatch hero or map and it will display information on said hero or map.

## Features

- Search Function
- Randomizer (Hero and Map)
- Hero and Map List
- Hero and Map Filter
- Hero and Map Info Display

## Technologies

- HTML
- CSS
- JavaScript

## Project Overview

This project allows users will be able to search up an Overwatch hero or map and it will display information on said hero or map. They can read simple information unique to what they search for and get a better look of the images via clicking on it, bringing up a separate tab of the image.

## How to Run

Run https://davidguixinpan.github.io/Overwatch-Database/ in your web browser
